## Statistical scope

This is a file and numerical-consistency check, not a certification of physical
accuracy or a new significance analysis. Seed spreads are sample standard
deviations of individual-model metrics. MD errors describe sampling within the
reported trajectories, not training-seed variability. An explicit early stop
can complete a fit without exhausting its configured budget.

The eleven fallacy types specified by the skill were screened for applicability (11/11):

| Type | Applicability to this check |
|---|---|
| Simpson's paradox | No pooled cross-system trend inferred; system/variant groups kept separate. |
| Ecological fallacy | No atom-level claim inferred from seed means; MD and seed uncertainties distinguished. |
| Berkson's paradox | No association estimated from the completed-run subset. |
| Collider bias | No adjusted causal model fitted. |
| Base-rate neglect | No diagnostic probabilities reported. |
| Regression to the mean | No claim of improvement based on extreme-seed selection. |
| Survivorship bias | Expected five-seed coverage checked; unfinished full-z groups explicitly retained as outstanding. |
| Look-elsewhere effect | No hypothesis tests or significance claims introduced. |
| Garden of forking paths | Primary checkpoint choices and historical variants retained in provenance; full-z snapshot mismatch flagged. |
| Correlation versus causation | No new causal inference made. |
| Reverse causality | No directional observational claim tested. |

These applicability checks do not replace a full manuscript statistical review.
